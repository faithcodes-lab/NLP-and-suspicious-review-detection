## 2. Preprocessing Notebook and Feature Engineering

A preprocessing notebook was introduced, which includes:

- Data loading and cleaning  
- Train test split  
- Feature engineering  

The engineered features include:

### Sentiment Features  
Derived from the best-performing sentiment model. Used to detect mismatches between review text and rating (e.g., positive text with low rating).

### Behavioural Features  
- Verified vs unverified reviews  
- Extreme ratings (e.g., consistently high ratings)

### Time-based Features  
- Review bursts  
- Unusual review frequency (e.g., multiple reviews within a short time)

### Linguistic Features  
- Very short reviews  
- Excessive punctuation (e.g., exclamation marks)  
- Generic phrases (e.g., “good”)  
- Personal pronoun usage  

### AI Probability Score  
Indicates likelihood that a review was AI generated.  
This is **not used as ground truth**, but as a supporting feature.
