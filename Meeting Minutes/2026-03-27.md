## 2. Feature Ablation for Model Improvement

A new approach was introduced:

### Feature Ablation

- A process of **systematically removing and re adding features**  
- Helps identify:
  - Which features improve performance  
  - Which features negatively impact the model  

Key points:

- Manual testing of feature combinations is inefficient and time consuming
- Feature ablation provides a more structured and automated approach  

This method will be used to improve model performance.
