# 1. Project Context

The project focuses on detecting **suspicious or fake reviews** within reviews collected from the **Amazon Shopping mobile application**.

The initial dataset available to the team contained **Amazon app reviews**, which included both textual reviews and metadata.

## Structure of the Amazon App Reviews Dataset

The dataset contained the following fields:

- Reviewer name  
- App version  
- Review date  
- Review text  
- Rating score  
- Thumbs-up count  
- Additional metadata related to the review

While the dataset contained useful review information, it **did not include labels identifying fake or genuine reviews**.

Because the objective of the project is to **train machine learning models for suspicious review detection**, a **labeled dataset was required**.

Therefore, the first stage of the project focused on **identifying suitable labeled datasets that could support supervised learning**.

---

# 2. Task Objectives

The primary objective for Week 1 was to **identify and evaluate datasets containing labeled fake or suspicious reviews** that could be aligned with the Amazon Shopping app review dataset.

## Main Task

**Request labeled data for suspicious / fake review detection (Amazon app reviews)**

The task required identifying datasets that satisfy the following criteria:

- Review-level labels (fake vs genuine)

# 3. Review of Existing Labeled Datasets

Multiple datasets were investigated to determine their suitability for suspicious review detection.

---

# 3.1 Deceptive Opinion Spam Dataset (Hotel Reviews)

**Source:** Ott et al. (2011)

This dataset contains **1,600 hotel reviews labeled as truthful or deceptive**.

## Dataset Structure

The dataset includes:

- Review text
- Binary labels (Truthful vs Deceptive)

## Labeling Methodology

The labels were created using a **controlled experimental setup**:

- **Truthful reviews** were collected from **TripAdvisor**
- **Deceptive reviews** were generated by **Amazon Mechanical Turk workers**

Participants were instructed to write **fake positive hotel reviews**, which created **ground-truth deceptive examples**.

## Strengths

- Clear labeling methodology
- Ground truth labels
- Frequently used in academic research

## Limitations

- Domain difference (hotel reviews vs e-commerce reviews)
- Does not include Amazon-specific metadata

Despite these limitations, the dataset was considered **useful for training baseline models for deceptive review detection**.

---

# 3.2 Fake Reviews Dataset (Deep Learning Research Dataset)

Another dataset was reviewed that focuses on **fake reviews on Amazon platforms**.

## Dataset Characteristics

The dataset contains:

- Amazon review text
- Binary labels indicating **fake vs genuine reviews**

## Labeling Methodology

According to the associated research paper, the labeling process relied on a **methodology for identifying fraudulent behaviour in verified and non-verified purchases**.

The study proposes techniques to distinguish between:

- Verified purchase reviews
- Non-verified purchase reviews
- Potentially deceptive reviews

## Limitations

While the dataset provides labeled reviews, the **detailed labeling methodology is not fully transparent**, which limits its reliability as a primary dataset.

---

# 3.3 Amazon Enhanced Fake Reviews Dataset (Kaggle)

**Source:** Kaggle – Harsh Decipher

This dataset includes Amazon product reviews labeled as:

- Fake / Spam reviews
- Genuine / Non-fake reviews

## Labeling Methodology

The dataset description indicates that labels were generated using **heuristic and rule-based techniques**, including:

- Duplicate review detection
- Rating deviation patterns
- Reviewer behaviour features

## Limitations

Although the dataset provides labels, the dataset documentation does **not provide a detailed explanation of the labeling process**.

Specifically:

- No named labeling algorithm is provided
- No peer-reviewed publication is directly associated with the dataset
- The exact rules used to assign labels are unclear

Because of these limitations, the dataset was considered **less reliable as a primary training dataset**.

---

# 3.4 Amazon Review Spam Dataset (Jindal & Liu, 2008)

Another dataset reviewed was the **Amazon Review Spam Dataset**, developed by **Jindal and Liu (2008)**.

## Dataset Structure

The dataset contains:

- Amazon product reviews
- Binary labels:
  - Spam / Fake reviews  
  - Non-spam / Genuine reviews

## Labeling Methodology

Labels were generated using **content-based and behavioral heuristics**, including:

- Duplicate or near-duplicate reviews across products
- Abnormal reviewer behaviour
- Repeated reviewing patterns
- Content similarity detection

## Strengths

- Clear methodology described in a peer-reviewed paper
- Widely cited in research
- Considered a benchmark dataset in opinion spam detection

## Limitations

- The dataset is relatively older
- Labels are heuristic-based rather
- Smaller scale compared to modern datasets

Despite these limitations, the dataset is considered **one of the most credible labeled datasets available for fake review research**.

# 6. Outcome of Week 1

The first week of the project focused on identifying reliable labeled datasets that could support suspicious review detection.

The investigation revealed that no publicly available dataset perfectly matches Amazon Shopping app reviews with clear fake review labels.

However, several alternative datasets were identified that can support model development, including:

- Deceptive Opinion Spam Dataset (Ott et al., 2011)
- Amazon Review Spam Dataset (Jindal & Liu, 2008)
- Amazon Enhanced Fake Reviews Dataset (Kaggle)

These datasets provide labeled examples of deceptive reviews, which can be used for model training, experimentation, or benchmarking.

Additionally, an attempt was made to obtain a more relevant app-store fake review dataset, although no response was received from the dataset authors.
